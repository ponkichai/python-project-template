# 規律の実体はハーネス外の層に置く

AIハーネス（Claude Code等）は数年単位で入れ替わる可能性が高く、特定ハーネスのhook・スキルに規律を実装するとロックインされる。そこで品質・セキュリティの規律の実体は、(1) リポジトリ層（pre-commit: Ruff・gitleaks・型チェック・テスト、およびCI）と (2) 環境層（devcontainer + egressファイアウォール）に置き、ハーネス層（`.claude/`）は「指示ファイルへの薄いアダプタ＋任意の多層防御ボーナス（危険コマンド遮断・プロンプトインジェクション検知）」に限定すると決めた。これにより人間だけの開発でも・どのエージェントで開いても同じ規律が効く。

## Consequences

- エージェント向け指示の正本はルート `AGENTS.md`（業界標準）。`CLAUDE.md` はそこへのシンボリックリンク
- `.claude/` を丸ごと削除してもテンプレートの品質保証は一切劣化しない（これが健全性のテスト）
- 新しい規律を追加するときは「pre-commit/CIで実装できないか」を先に検討し、ハーネスhookは最後の手段とする
